# План задач PersonalAssistant

## Как устроен список

- Бизнесовые задачи имеют числовые ID: `010`, `011` и далее.
- Технический долг и найденные проблемы имеют ID `TD-001`, `TD-002` и далее.
- После выполнения задача исчезает из этого файла, но навсегда остается в `docs/tasks/`.
- ID не переиспользуются и не меняются, поэтому по нему можно найти ветку, коммит и архив.

## Бизнесовые задачи

### MVP 1

Цель MVP 1 — дать пользователю законченный цикл учета обязательных платежей: создать платеж, увидеть его, отметить оплату, посмотреть историю, получить статистику и напоминание.

### Задача 010. Напоминания

- `BackgroundService`;
- напоминания до даты, в день платежа и после просрочки;
- учет часового пояса;
- защита от повторной отправки за один день;
- разные сообщения для обычных и автоматических платежей.

### Задача 011. Настройки пользователя

- время отправки напоминаний;
- валюта по умолчанию;
- повторное изменение часового пояса;
- единое меню `/settings`.

## Технический долг и качество

### TD-001. Интеграционные проверки и эксплуатация

- integration tests с PostgreSQL;
- проверка изоляции пользователей;
- проверка восстановления диалога после перезапуска;
- health endpoint;
- структурированные логи;
- безопасное применение миграций.

### TD-002. Идемпотентность Telegram Update

- постоянный журнал обработанных Telegram Update для полной идемпотентности;

### TD-003. Декомпозиция Telegram-слоя

- декомпозиция `TelegramPollingService` на маршрутизацию, форматирование и обработчики команд;
- разбиение длинных сообщений истории и статистики;

## Когда можно запускать

### Технический запуск

Уже возможен после настройки `TELEGRAM_BOT_TOKEN`, PostgreSQL и применения миграций. Текущие команды: `/start`, `/settings`, `/add`, `/payments`, `/upcoming`, `/edit`, `/disable`, `/pay`, `/history`, `/stats`, `/help`.

### Ограниченный запуск для одного пользователя

Возможен после задачи 009. Доступны редактирование, отключение, отметка оплаты, история и статистика; запуск можно ограничить одним Telegram User ID.

### MVP 1 для регулярного использования

Рекомендуется после бизнесовых задач 010–011 и технического долга TD-001. Тогда появятся напоминания, пользовательские настройки, интеграционные проверки и эксплуатационные проверки.
