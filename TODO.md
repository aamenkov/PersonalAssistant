# Будущие задачи

- Реализовать создание, просмотр и редактирование платежей через Telegram-сценарии.
- Добавить оплату, историю и месячную статистику.
- Добавить `BackgroundService` напоминаний и настройки времени.
- Добавить полноценные интеграционные тесты PostgreSQL.
- Поддержать устойчивый «день месяца» для платежа 29–31 числа.
- Добавить миграции в CI и безопасное применение миграций при деплое.
- Добавить метрики, health endpoint и обработку Telegram retry.
