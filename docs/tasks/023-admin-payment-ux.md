# Задача 023. Иконки способов оплаты, UX-кнопки и админская панель

## Решение

- Для способов оплаты добавлены отдельные иконки: карта `💳`, банковский перевод `🏦`, наличные `💵`, другой способ `💰`.
- Карту и банковский перевод не объединяли: это разные способы оплаты и полезные будущие признаки для аналитики.
- В сценарии изменения периодичности проверка клавиатуры даты выполняется раньше проверки периодичности. Поэтому после выбора периодичности пользователь получает только варианты даты, а кнопки прошлого шага не остаются.
- Добавлена необязательная настройка `TELEGRAM_ADMIN_USER_ID` / `Telegram:AdminUserId`. При заданном ограниченном списке доступа администратор также получает доступ к боту. Без значения администратором считается единственный пользователь в `TELEGRAM_ALLOWED_USER_IDS`; при пустом списке администратор автоматически не назначается.
- В админской панели добавлены два действия с подтверждением:
  - очистить историю оплат, сохранив платежи и расписания;
  - удалить платежи и историю текущего пользователя.
- Полное удаление ограничено текущим пользователем, профиль пользователя сохраняется. Транзакции удаляются перед платежами из-за внешнего ключа `Restrict`; связанные напоминания удаляются каскадно базой.

## Изменения

- добавлены `AdminService`, `BotAdminPolicy` и owner-scoped операции репозитория;
- добавлены кнопка админской панели и callback-сценарии подтверждения;
- обновлены `.env.example`, Docker Compose, README, инструкция развертывания, требования и архитектура;
- удалены неиспользуемые прокси-методы клавиатур из polling-сервиса.
