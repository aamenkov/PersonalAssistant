## Результат аудита

Исправлено:

- обязательная конфигурация проверяется на пустые значения;
- миграции применяются до запуска Telegram polling;
- добавлен design-time factory для EF Core;
- диалог корректно переключается между созданием, редактированием и оплатой;
- финальная операция и удаление состояния сохраняются одним `SaveChanges`;
- дата оплаты по умолчанию учитывает часовой пояс пользователя;
- суммы принимают точку или запятую без неоднозначных разделителей;
- месяц проверяется строго в формате `YYYY-MM`;
- команды сопоставляются по точному имени, неизвестная команда получает ответ;
- исправлена callback-кнопка отмены отключения;
- `/start` не запрашивает часовой пояс повторно;
- добавлено необязательное ограничение одним Telegram User ID;
- транзакция хранит ожидаемую сумму для стабильной исторической статистики.

Оставлено для следующих задач:

- автоматические напоминания;
- полноценные PostgreSQL integration tests;
- постоянный журнал обработанных Telegram Update;
- декомпозиция крупного Telegram-обработчика;
- разбиение сообщений длиннее лимита Telegram.
