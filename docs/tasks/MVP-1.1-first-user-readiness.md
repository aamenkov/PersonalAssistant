# Текущая задача

## ID задачи

MVP-1.1

## Этап

Подготовка проекта к комфортному запуску для первого пользователя.

## Ветка

`codex/MVP-1.1-first-user-readiness`

## Цель

Объединить в одну поставку исправления, которые напрямую влияют на первый пользовательский опыт: устойчивость Telegram API, доступ нескольких пользователей, главное меню, русские кнопки и базовые пользовательские настройки.

## Задачи этапа

- [x] Добавить устойчивую обработку временных сетевых ошибок Telegram API.
- [x] Поддержать список разрешённых Telegram User ID.
- [x] Добавить активное главное меню и русские кнопки в ключевых сценариях.
- [x] Улучшить выбор часового пояса и даты.
- [x] Перенести валюту по умолчанию и настройки уведомлений в профиль пользователя.
- [x] Исключить ежедневную периодичность и уточнить пользовательские названия (переименование пользовательских формулировок оставлено отдельной задачей 015).
- [x] Добавить миграцию, unit-тесты и обновить документацию.

## Критерии готовности

- Сборка и тесты проходят.
- Поведение соответствует требованиям первого пользовательского запуска.
- Полноценные автоматические напоминания остаются отдельной задачей 010 и не входят в эту ветку.
- Перед Pull Request файл перемещен в `docs/tasks/MVP-1.1-first-user-readiness.md`.
