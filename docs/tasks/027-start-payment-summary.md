# Задача 027. Унифицировать приветственную карточку ближайшего платежа

В приветствии после `/start` формат ближайшего платежа теперь переиспользует `TelegramUi.FormatUpcomingCard`. Благодаря этому:

- исчезает дублирование `сегодня · сегодня`;
- сохраняются иконки способов оплаты;
- формат даты совпадает с разделом «Ближайшие платежи»;
- просроченные платежи используют ту же карточку с приоритетом `⚠️`.

Дополнительно устранен связанный UX-баг в сценарии ежегодного платежа: после выбора «Каждый год» больше не показываются неподходящие быстрые кнопки «Сегодня», «Завтра» и другие варианты. Пользователь вводит дату ежегодного платежа вручную в формате `ДД.ММ.ГГГГ`.

Формат карточек дополнительно унифицирован: ближайшие платежи показывают сумму и расписание в одной строке, дата — без лишнего года, а расстояние выводится полностью (`через 6 дней`). В годовой статистике используется нейтральный заголовок `2026 год` вместо слова «прогноз», а подписи сумм совпадают с месячной статистикой.
