# Текущая задача

## Номер

006

## Этап

Редактирование и отключение платежей.

## Ветка

`codex/006-payment-editing`

## Цель

Дать пользователю возможность изменять параметры собственного платежа и отключать его без удаления истории.

## Задачи этапа

- [x] Реализовать выбор платежа и сценарий редактирования.
- [x] Реализовать изменение поддерживаемых параметров платежа.
- [x] Реализовать деактивацию платежа вместо физического удаления.
- [x] Проверить принадлежность платежа текущему пользователю.
- [x] Добавить unit-тесты.
- [x] Обновить документацию.
- [x] Запустить проверки.

## Критерии готовности

- Сборка и тесты проходят.
- Изменение платежа не меняет историю оплат.
- Неактивные платежи не отображаются среди активных и ближайших.
- Перед Pull Request файл перемещен в `docs/tasks/006-payment-editing.md`.
