# 022 — Переработка Telegram UX и навигации

## Выполнено

- Reply Keyboard оставлена глобальной навигацией, действия над платежом перенесены в отдельные inline-карточки;
- `/payments` и `/upcoming` показывают каждый платеж отдельным сообщением с собственными действиями;
- добавлено контекстное меню дополнительных действий и возврат к карточке;
- редактирование поддерживает выбор конкретного поля: сумма, расписание, способ оплаты, автосписание, название и комментарий;
- расписание, даты, деньги и часовые пояса отображаются в пользовательском формате;
- добавлены русские быстрые даты, включая «Через неделю», при сохранении ISO-ввода для совместимости;
- `/stats` и `/history` открывают текущий месяц и поддерживают кнопки предыдущего/следующего месяца;
- `/start` показывает короткое резюме ближайшего платежа без IANA timezone;
- обновлены README и ARCHITECTURE;
- добавлены тесты человекочитаемого расписания, быстрых дат и редактирования одного поля.

## Ограничения

- Telegram-сообщения карточек пока отправляются отдельными сообщениями; редактирование существующего сообщения оставлено для отдельной оптимизации;
- выбор конкретного дня месяца и полноценный календарь остаются в задаче 016;
- постоянный журнал Telegram Update и декомпозиция polling-класса остаются техническим долгом.
