# TD-009. Финальный аудит и упрощение перед MVP 2

## Цель

Подготовить проект к публикации как MVP 2: проверить код, документацию, конфигурацию и эксплуатационные риски, исправить найденные ошибки и упростить реализацию без внедрения лишних паттернов.

## Ветка

`codex/TD-009-mvp2-readiness`

## Выполнено

- актуализированы `README.md`, `REQUIREMENTS.md`, `ARCHITECTURE.md`, `AGENTS.md`, `TODO.md` и инструкция развертывания;
- добавлена отдельная инструкция по созданию, хранению и проверке резервных копий PostgreSQL;
- автоматизация резервного копирования вынесена в будущую задачу `TD-010`;
- пароль PostgreSQL сделан обязательным, health endpoint ограничен localhost, контейнерам добавлена политика перезапуска;
- добавлен `.dockerignore`, а дампы базы исключены из Git;
- полное административное удаление платежей и истории сделано атомарным;
- исправлено обновление расчетного дня после изменения периодичности и даты платежа;
- удалены неиспользуемые методы Telegram UI и устранен лишний запрос пользователя в `/settings`;
- уточнена подпись настройки предварительного напоминания;
- обновлены уязвимые зависимости и устранены предупреждения анализаторов;
- добавлен регрессионный тест изменения периодичности платежа.

## Архитектурное решение

Крупные файлы `Program.cs` и `PaymentServices.cs` не разделялись механически перед релизом. Такое перемещение большого объема рабочего кода не меняет поведение, но повышает риск регрессий. В рамках задачи удален мертвый код и исправлены конкретные точки риска. Дальнейшее разделение следует выполнять вместе с функциональными изменениями, когда появится четкая новая ответственность.

- `dotnet test PersonalAssistant.sln --no-build` — успешно, 78 тестов;
- `dotnet format PersonalAssistant.sln --verify-no-changes --no-restore` — успешно;
- `dotnet list PersonalAssistant.sln package --vulnerable --include-transitive` с официальным NuGet-источником — уязвимые пакеты не найдены;
- `docker compose config` с тестовыми переменными — успешно;
- `git diff --check` — успешно;
- локальная сборка Docker-образа не запускалась: Docker Desktop не был запущен. Compose-конфигурация проверена, образ необходимо пересобрать на VPS или при запущенном Docker перед публикацией.
