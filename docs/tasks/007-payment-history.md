# Текущая задача

007

## Этап

Оплата и история транзакций.

## Ветка

`codex/007-payment-history`

## Цель

Дать пользователю возможность отметить платеж оплаченным, сохранить фактическую транзакцию и получить следующий срок оплаты.

- [x] Запросить фактическую сумму и дату оплаты.
- [x] Создать неизменяемую `PaymentTransaction`.
- [x] Рассчитать следующую дату с учетом периодичности.
- [x] Деактивировать однократный платеж после оплаты.
- [x] Добавить просмотр истории оплат.
- [x] Проверить принадлежность платежа текущему пользователю.
- [x] Добавить unit-тесты.
- [x] Обновить документацию.
- [x] Запустить проверки.

## Критерии готовности

- Сборка и тесты проходят.
- Фактическая сумма транзакции не зависит от текущей суммы платежа.
- Регулярный платеж получает корректную следующую дату.
- Однократный платеж становится неактивным после оплаты.
- Перед Pull Request файл перемещен в `docs/tasks/007-payment-history.md`.
