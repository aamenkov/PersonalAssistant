# Задача 026. Улучшить отображение даты ближайшего платежа

В карточке ближайшего платежа устранено дублирование относительной даты:

- сегодня отображается как `сегодня`;
- завтра отображается как `завтра`;
- более поздние даты показывают календарную дату и относительный срок;
- просроченные платежи сохраняют формулировку `Срок был ...`.

Проверки: `dotnet build`, `dotnet test` — 72 теста успешно, `git diff --check` — успешно.
