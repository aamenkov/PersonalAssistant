# Задача 025. Определение российского часового пояса по текущему времени

## Решение

- В списке часовых поясов сохранены быстрые кнопки популярных городов, включая `Москва (UTC+3)`.
- Добавлена кнопка «Указать текущее время» и ввод местного времени в формате `ЧЧ:ММ`.
- Бот сравнивает введенное время с UTC, определяет российское целочасовое смещение от `UTC+02:00` до `UTC+12:00` и просит подтвердить результат.
- Для Москвы пользователь получает `UTC+03:00`. Для других регионов России определяется соответствующее смещение, например `UTC+05:00`.
- Фиксированные offset-зоны поддерживаются единым `TimeZoneResolver` вместе с IANA-зонами и корректно восстанавливаются после перезапуска.
- Сценарий доступен и при первом `/start`, и из настроек.
