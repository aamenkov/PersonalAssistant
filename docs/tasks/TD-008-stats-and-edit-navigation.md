# TD-008. Исправление навигации статистики и действий платежа

## Выполнено

- кнопка «📊 Статистика» теперь вызывает `/stats` без аргументов и открывает статистику текущего локального месяца;
- обработка `/stats ГГГГ-ММ` сохранена для ручного выбора месяца;
- кнопка «⏸ Отключить платеж» удалена из карточки платежа;
- отключение доступно только внутри меню «✏️ Изменить»;
- аналогичная нормализация месяца применена к навигации истории через кнопку.
