# 021 — Навигация статистики и настройки

Задача выполнена в ветке `codex/021-stats-settings-navigation`.

## Выполнено

- кнопка «📊 Статистика» сразу открывает текущий локальный месяц;
- добавлена inline-навигация по предыдущему и следующему месяцу, включая переходы через границу года;
- история также открывается за текущий месяц и поддерживает такую же навигацию;
- экран настроек показывает человекочитаемые текущие значения часового пояса, валюты, дней и времени напоминания;
- добавлен годовой прогноз по каждой валюте: запланировано, уже оплачено, осталось и количество платежей;
- обновлены требования, архитектура и README;
- добавлен unit-тест годового расчета.

## Правила расчета

- разные валюты не суммируются;
- прогноз строится по активным платежам и их расписанию на выбранный год;
- фактические расходы берутся из исторических транзакций за этот год;
- оплаченная плановая дата восстанавливается по `PaidPeriod`, даже если текущая дата платежа уже сдвинута вперед.
