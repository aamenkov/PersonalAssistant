# PersonalAssistant

PersonalAssistant — расширяемый Telegram-бот, первым модулем которого становится учет регулярных и обязательных платежей.

Бот поддерживает создание, редактирование и отключение платежей, запись оплат, историю, месячную статистику и автоматические напоминания с учетом часового пояса. При настройке можно выбрать популярный город или указать текущее российское время, чтобы бот определил смещение. Проект подготовлен к ограниченному запуску для одного пользователя.

## Технологии

- C# и .NET 8;
- ASP.NET Core Web Host с Telegram polling и health endpoint;
- Telegram Bot API;
- Entity Framework Core и PostgreSQL;
- Docker Compose;
- встроенный Dependency Injection и `ILogger`.

## Команды бота

- `/start` — регистрация, выбор часового пояса и показ главного меню;
- `/settings` — часовой пояс, валюта по умолчанию и настройки напоминаний;
- `/add` — последовательное добавление платежа;
- `/payments` — список активных платежей;
- `/upcoming` — просроченные, ближайшие 7 дней и следующий платеж;
- `/edit` — изменить параметры платежа;
- `/disable` — отключить платеж без удаления истории;
- `/pay` — отметить платеж оплаченным (совместимость; в основном сценарии используется кнопка «Оплатил»);
- `/history [YYYY-MM]` — история текущего или выбранного месяца;
- `/stats [YYYY-MM]` — статистика текущего или выбранного месяца;
- `/help` — справка.

В многошаговых сценариях используются русские кнопки. Дата регулярного расхода не может быть в прошлом. После сохранения или отмены временные кнопки заменяются главным меню.

Главное меню используется для перехода между разделами, а действия над конкретным платежом находятся на его inline-карточке. Списки платежей показываются отдельными карточками, поэтому кнопки оплаты и редактирования всегда относятся к понятному платежу. Редактирование позволяет выбрать только нужное поле.

Для месячного платежа доступны 1-е число, 15-е число, последний день месяца или произвольная дата. Ежегодная и произвольная дата вводятся единообразно в формате `ДД.ММ.ГГГГ`.

Для даты доступны быстрые варианты: сегодня, завтра, первое число следующего месяца и то же число следующего месяца. Повторная доставка подтверждения оплаты не должна создавать вторую оплату за тот же период.

Способы оплаты отображаются иконками: карта, банковский перевод, наличные и другой способ. Карта и банковский перевод остаются раздельными, чтобы не потерять смысл в будущей статистике. При заданном `TELEGRAM_ADMIN_USER_ID` появляется админская панель с подтверждаемой очисткой истории или полным удалением платежей текущего пользователя.

Напоминания проверяются фоновым worker-ом раз в минуту. Они отправляются до даты платежа, в день платежа и после наступления срока, с учетом часового пояса и времени пользователя. Для каждого платежа и дня отправляется не более одного одинакового напоминания; кнопка «Оплатил» открывает сценарий записи оплаты.

Из напоминания можно выбрать «Напомнить позже»: через час, сегодня вечером или завтра. Отложенное время хранится отдельно от даты платежа и рассчитывается по часовому поясу пользователя.

Текущую версию можно запускать для одного пользователя с учетом платежей и автоматическими напоминаниями. Для ограничения доступа задайте `TELEGRAM_ALLOWED_USER_IDS`.
