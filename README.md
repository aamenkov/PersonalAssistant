# PersonalAssistant

PersonalAssistant — расширяемый Telegram-бот, первым модулем которого становится учет регулярных и обязательных платежей.

MVP 2 поддерживает создание, редактирование и отключение платежей, запись оплат, историю, месячную и годовую статистику, автоматические напоминания и snooze с учетом часового пояса. При настройке можно выбрать популярный город или указать текущее российское время, чтобы бот определил смещение. Доступ можно ограничить списком Telegram User ID.

## Технологии

- C# и .NET 8;
- ASP.NET Core Web Host с Telegram polling и health endpoint;
- Telegram Bot API;
- Entity Framework Core и PostgreSQL;
- Docker Compose;
- встроенный Dependency Injection и `ILogger`.

```bash
dotnet build PersonalAssistant.sln
dotnet test PersonalAssistant.sln
docker compose config
dotnet list PersonalAssistant.sln package --vulnerable --include-transitive --source https://api.nuget.org/v3/index.json
```

Для полного прогона интеграционных тестов с миграциями и имитацией Telegram запустите отдельный тестовый PostgreSQL 16. Команды ниже используют только локальный тестовый контейнер и одноразовые реквизиты:

```powershell
docker run --detach --rm --name personalassistant-test-postgres -p 127.0.0.1:57443:5432 -e POSTGRES_USER=pa_029_test -e POSTGRES_PASSWORD=pa_029_test_only -e POSTGRES_DB=postgres postgres:16
docker exec personalassistant-test-postgres pg_isready -U pa_029_test -d postgres
$env:PA_029_TEST_POSTGRES_PORT = '57443'
dotnet test PersonalAssistant.sln
Remove-Item Env:PA_029_TEST_POSTGRES_PORT
docker stop personalassistant-test-postgres
```

Запускайте тесты после ответа `accepting connections`. Без указанного порта тесты, требующие PostgreSQL, пропускаются.

## Команды бота

- `/start` — начало работы;
- `/settings` — настройки;
- `/add` — последовательное добавление платежа;
- `/payments` — список активных платежей;
- `/upcoming` — просроченные, ближайшие 7 дней и следующий платеж;
- `/edit` — изменить параметры платежа;
- `/disable` — отключить платеж без удаления истории;
- `/pay` — отметить платеж оплаченным (совместимость; в основном сценарии используется кнопка «Оплатил»);
- `/history [YYYY-MM]` — история текущего или выбранного месяца;
- `/stats [YYYY-MM]` — статистика текущего или выбранного месяца;
- `/help` — справка.

В многошаговых сценариях используются русские кнопки. Дата регулярного расхода не может быть в прошлом. После сохранения или отмены временные кнопки заменяются главным меню.

Главное меню используется для перехода между разделами, а действия над конкретным платежом находятся на его inline-карточке. Списки платежей показываются отдельными карточками, поэтому кнопки оплаты и редактирования всегда относятся к понятному платежу. Редактирование позволяет выбрать только нужное поле.

Для месячного платежа доступны 1-е число, 15-е число, последний день месяца или произвольная дата. Ежегодная и произвольная дата вводятся единообразно в формате `ДД.ММ.ГГГГ`.

Для даты доступны быстрые варианты: сегодня, завтра, первое число следующего месяца и то же число следующего месяца. Повторная доставка подтверждения оплаты не должна создавать вторую оплату за тот же период.

Способы оплаты отображаются иконками: карта, банковский перевод, наличные и другой способ. Карта и банковский перевод остаются раздельными, чтобы не потерять смысл в будущей статистике. При заданном `TELEGRAM_ADMIN_USER_ID` появляется админская панель с подтверждаемой очисткой истории или полным удалением платежей текущего пользователя.

### Напоминания

Откройте **Настройки → Напоминания**, чтобы выбрать режим, время и поведение после просрочки:

- Обычный — одно напоминание заранее (или ни одного при 0 дней) и одно в день оплаты.
- Настойчивый — ежедневные напоминания за 1–30 дней до оплаты и в день оплаты.
- Критический — ежедневные напоминания заранее и повторы в день оплаты через 1, 2 или 3 часа в выбранном окне. После просрочки частые повторы можно включить отдельно.

Предпросмотр показывает будущие события по реальному платежу и местному времени. Правки сразу видны на экране, но не влияют на рассылку до сохранения. В разделе **Изменить → Напоминания** конкретного платежа можно задать отдельный профиль, вернуть общий или выключить уведомления. Отключение удаляет индивидуальный профиль; повторное включение возвращает общие настройки.

Кнопка «Напомнить позже» предлагает варианты через 1 или 3 часа, до 19:00 сегодня, до 09:00 завтра или на выбранные дату и время. Отсрочку можно перенести либо отменить. Она не меняет срок оплаты. «Оплатил» и «Напомнить позже» относятся к сроку на карточке; старые кнопки без срока предложат открыть актуальный платёж.

Worker проверяет расписание раз в минуту. После простоя не отправляет все пропущенные слоты. Если Telegram мог принять запрос, но результат неизвестен, автоматического повтора нет, чтобы не создавать дубликаты.

Для закрытого запуска задайте `TELEGRAM_ALLOWED_USER_IDS`. Пустое значение разрешает доступ всем пользователям и не рекомендуется для персонального VPS-развертывания.
