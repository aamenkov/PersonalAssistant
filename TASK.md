# Текущая задача

## Номер

005

## Этап

Создание и просмотр регулярных платежей.

## Ветка

`codex/005-payment-creation-and-listing`

## Цель

Реализовать первый полноценный пользовательский сценарий учета платежей через Telegram.

## Задачи этапа

- [ ] Реализовать последовательное добавление платежа через `/add`.
- [ ] Хранить состояние диалога в `ConversationState`.
- [ ] Добавить подтверждение перед сохранением платежа.
- [ ] Реализовать просмотр всех активных платежей через `/payments`.
- [ ] Реализовать просмотр ближайших платежей через `/upcoming`.
- [ ] Проверять принадлежность платежа текущему пользователю.
- [ ] Добавить unit-тесты валидации и application-сценария.
- [ ] Обновить README и документацию сценариев.
- [ ] Запустить `dotnet build`, `dotnet test` и `docker compose config`.
- [ ] Перенести эту задачу в `docs/tasks/005-payment-creation-and-listing.md` перед Pull Request.

## Критерии готовности

- Пользователь может пройти сценарий `/add` после перезапуска приложения.
- В БД сохраняется только платеж текущего пользователя.
- `/payments` и `/upcoming` показывают понятный результат, включая отсутствие платежей.
- Сборка, тесты и Docker Compose проходят.
- Завершенная задача архивирована, а этот файл обновлен для следующей задачи до создания Pull Request.

## Ограничения

Оплата, история транзакций, статистика и напоминания будут отдельными задачами.
